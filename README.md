# 根號冒險譚：勇者算術試煉 ⚔️

專為國中二年級學生設計的平板友善數學 RPG 教育網頁遊戲！

## 🌟 遊戲單元與關卡
- **第 1 關：根號化簡**（提出平方因數化為最簡根式，等級上限 Lv.5）
- **第 2 關：根號加減**（先化簡後合併同類方根，等級上限 Lv.5）
- **第 3 關：根號乘法**（利用 $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$ 運算與化簡，等級上限 Lv.5）
- **第 4 關：根號除法**（利用 $\sqrt{a} \div \sqrt{b} = \sqrt{a \div b}$ 整除運算與化簡，精選題庫無需分母有理化，等級上限 Lv.5）

## 🎮 核心特色
1. **平板友善設計**：專屬 $4 \times 4$ 大型虛擬觸控鍵盤，解決平板輸入根號 $\sqrt{}$ 的痛點。
2. **RPG 成長機制**：10 位各具特色的勇者角色可選，隨關卡擊敗怪獸提升等級、EXP 與攻擊力。
3. **學生名冊登記**：支援輸入班級、座號與真實姓名，自訂角色暱稱（最多6字）。
4. **雲端即時同步與永久引繼碼**：每位學生角色擁有專屬永久引繼碼（如 `RAD-123456`），自動同步至 Firebase 雲端，換平板隨時還原。
5. **教師最高權限管理後台**：任課教師可密碼登入後台查詢全班學生名冊、引繼碼與各關進度，支援一鍵匯出 Excel (CSV) 離線備份與列印。
6. **防重複題目與詳解**：攻擊題目隨機防連續重複，答錯即時提供完整步驟詳解與教學指引。
7. **神速暴擊**：5 秒內快速答對觸發 1.5 倍神速暴擊，兼顧速度與準確度。
