# 根號冒險譚：勇者算術試煉 ⚔️

適合國中二年級學生遊玩的數學 RPG 教育遊戲！

## 🌟 遊戲單元與關卡
- **第 1 關：根號化簡**（提出平方因數化為最簡根式，等級上限 Lv.5）
- **第 2 關：根號加減**（先化簡後合併同類方根，等級上限 Lv.5）
- **第 3 關：根號乘法**（利用 $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$ 運算與化簡，等級上限 Lv.5）
- **第 4 關：根號除法**（敬請期待）

## 🎮 核心特色
1. **平板友善設計**：專屬 $4 \times 4$ 大型虛擬觸控按鈕，解決在平板上輸入根號 $\sqrt{}$ 的痛點。
2. **RPG 成長機制**：10 位風格角色可選，隨關卡擊敗怪獸提升等級與攻擊力。
3. **神速暴擊**：5 秒內快速答對觸發 1.5 倍暴擊，兼顧速度與準確度。
4. **跨裝置引繼碼**：支援產生備份代碼，學生回家可跨裝置繼承等級。
